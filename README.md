# Carmen Gimeno · diseño gráfico & diseño web

✏️Web profesional de carmen gimeno, diseñadora gráfica y web freelance.

Portfolio para presentar los resultados, filosofia y procesos de proyecto.

Trabajo desarrollado como proyecto final en el curso de THML; CSS y JavaScript de la escuela CEI

🔗 **Enlace web:** [cegimeno.com](https://cegimeno.com)


## Sobre el proyecto

El objetivo de la web es presentar mis trabajos, facilitar el contacto para futuros clientes y contar/mostrar la metodología de trabajo entre diseñadora-cliente. 

Tiene mucha importancia la imagen visual y generación de una identidad gráfica para la web. Se trabaja un estilo gráfico en la web que esté en consonancia con el estilo de los trabajos presentados y que sirva como carta de presentación.

## Carcaterísticas técnicas
- La página web está construida con HMTL, CSS y JavaScript
- Los colores, las tipografías y la altura de la cabecera se guardan en variables CSS
- El diseño es responsive utilizando la regla @media (media query)
- Las partes que se repiten en varias páginas son Web Components en global.js
